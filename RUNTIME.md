# Corvo Flash — Runtime build

Corvo Flash is a Telegram social-trading companion built for the Definitive Flash track.

## Demo loop

1. Open the Telegram companion.
2. Track a trader wallet.
3. Receive a signal when the trader buys.
4. Review the trade details.
5. Confirm from the user's own wallet/device.
6. Manage DCA, stop-loss, take-profit, and open orders.

## Safety

- Review mode is the default demo flow.
- The product does not require the user's private key.
- Production credentials, databases, and runtime state are excluded from this repository.
